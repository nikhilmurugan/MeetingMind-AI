# Changelog

All notable changes to **MeetingMind AI** will be documented in this file.

## [1.0.0] - 2026-08-23
### Added
- **LLM Provider Router**: Priority routing with OpenRouter API and automatic fallback to local Ollama (`qwen2.5-coder:3b`).
- **OpenAI Whisper Integration**: Local speech-to-text transcription with lazy loading & model caching.
- **Executive PDF Export**: One-click printable PDF report generation.
- **Action Items Kanban View**: Priority column layout (`High`, `Medium`, `Low`) with interactive status toggles.
- **Instant Demo Mode**: Built-in zero-upload demo meeting loader for immediate evaluation.
- **Date Range Filters**: History filtering by `Today`, `This Week`, and `This Month`.
- **Search Highlighting**: Real-time dialogue search with text mark highlighting in transcript cards.
- **Sentiment Analysis & Statistics**: Automated sentiment determination and processing statistics computation.
